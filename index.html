📜 Comandos do Bot

O bot foi desenvolvido para otimizar a experiência do servidor, oferecendo guias visuais, uma rede social interna e uma IA sarcástica. Alguns dos principais comandos incluem:


/como_enfrentar_killer & /listar_killers

Geram guias visuais detalhados com dicas estratégicas, vídeos e informações sobre o banco de dados do servidor.

/postar & /favoritas_postagens

Criam publicações no feed do servidor (com sistema de curtidas e tópicos de comentários) e permitem salvar postagens em uma lista privada de favoritos.

/ia

Interage com uma Inteligência Artificial (Google Gemini) configurada com regras estritas de segurança e escopo restrito ao tema do servidor.

Comandos de Setup (Admins)

/configurar permite que administradores definam o canal exato onde as postagens do feed serão enviadas.

⚖️ Termos de Serviço (ToS)

Ao utilizar o bot no seu servidor, você concorda com as seguintes regras:

  • Uso da Inteligência Artificial: A IA do bot possui filtros de segurança. É estritamente proibido tentar burlar esses filtros para gerar discurso de ódio, assédio, conteúdo sexual, apologia a crimes ou temas políticos. O desenvolvedor não se responsabiliza pelas respostas geradas pela IA, mas toma medidas para restringir conteúdos impróprios.
  • Rede Social e Publicações: Os usuários são os únicos responsáveis pelo conteúdo que publicam via comando /postar. É proibido postar imagens ou textos que violem os Termos de Serviço do Discord (NSFW, violência explícita, etc.).
  • Disponibilidade do Serviço: O desenvolvedor reserva o direito de realizar manutenções, atualizações ou interromper o serviço a qualquer momento. O bot utiliza um banco de dados local para salvar as informações.
  • Propriedade Intelectual: Este bot é um projeto feito por fã e não é um produto oficial. Nomes de personagens e referências ao jogo pertencem aos seus respectivos criadores.

🔒 Política de Privacidade

A privacidade dos usuários é levada a sério. A coleta de dados é estritamente voltada para o funcionamento das ferramentas do bot:


1. Quais dados armazenamos?

  • Identificadores: ID do Usuário do Discord, ID da mensagem postada e ID do Servidor.
  • Dados de Postagens: Título, texto e URL da imagem enviados via comando /postar.
  • Favoritos e Curtidas: Lista de IDs de mensagens que cada usuário curtiu ou favoritou.
  • Configurações do Servidor: ID do canal configurado para receber o feed de postagens.

2. O que NÃO coletamos? (Muito Importante)

  • O bot NÃO armazena o conteúdo de conversas gerais do servidor. Ele apenas lê os comandos de barra (Slash Commands) quando acionados.
  • Não armazenamos histórico de conversas com a IA. As perguntas feitas no comando /ia são enviadas para a API do Google Gemini para gerar a resposta, mas não ficam salvas no banco de dados do bot.

3. Como seus dados são usados?

Os dados armazenados servem única e exclusivamente para manter o funcionamento do feed (para que as curtidas e favoritos não sumam quando o bot reiniciar) e para exibir as listas de pesquisa.

4. Exclusão de Dados

Caso deseje que suas postagens ou interações sejam removidas, você pode deletar a sua própria mensagem no canal de feed. Se desejar apagar todo o seu histórico de favoritos e curtidas, ou se for um administrador querendo limpar os dados do servidor, entre em contato com o desenvolvedor via suporte.
